# 跨境百宝囊 · 纯本地版 · 部署说明

> 这是什么：一个**只有前端静态页面**的版本。没有 Supabase、没有任何服务器端代码、
> 没有账号密码。用户点「进入」即用，所有数据保存在**用户自己的浏览器**（IndexedDB）里，
> 不向任何服务器上传数据。
>
> 部署目标：任意静态托管（腾讯云 CloudBase / Cloudflare Pages / 服务器 Nginx 均可）。
> 全部功能免费，托管平台免费额度足够长期使用。

---

## 一、这个包里有什么

```
跨境百宝囊-纯本地版/
├── index.html          入口页（启动页只有一个「进入」按钮）
├── css/                样式（含本地化的 Inter 字体声明）
├── fonts/              Inter 字体文件（本地托管，不请求 Google）
└── js/                 全部逻辑（已去除 Supabase / 协作 / 云同步代码）
```

与双模式版相比删除的内容（不需要你做任何事，仅备查）：

| 删除项 | 原用途 | 删除后影响 |
|---|---|---|
| js/config.js + js/supabase.js + vendor/supabase.umd.js | 连接 Supabase | 无，不再有云端登录 |
| js/collab.js → js/localcollab.js | 成员/分享/角色 | 「分享」按钮会提示改用导出备份 |
| js/migrate.js | 云端数据迁移 | 恒为空操作 |

保留的联网功能（都是可选、直连第三方公共 API，与你的服务器无关）：

- 汇率（cdn.jsdelivr.net，失败自动换源 + 本地缓存）
- 世界时钟城市搜索、免费翻译引擎

## 二、部署方式（三选一，都是「上传文件」这一件事）

### 方式 A · 腾讯云 CloudBase 静态托管（国内访问最快）

1. 腾讯云控制台搜「CloudBase」→ 开通（选按量付费，静态托管有免费额度）→ 记下环境 ID
2. 静态网站托管 → 文件管理 → 把包内 `index.html、css/、fonts/、js/` 四项一起拖到根目录 `/`
   （注意：是这 4 项的内容，不要套多一层文件夹）
3. 得到 `https://环境ID.tcloudbaseapp.com`，完成。

CLI 等价命令：

```bash
npm i -g @cloudbase/cli
tcb login
tcb hosting deploy ./ -e 你的环境ID -p /
```

### 方式 B · Cloudflare Pages（国际访问最快，也免费）

1. [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Pages → **Upload assets**
2. 把包内 4 项拖进去 → Deploy → 得到 `https://xxx.pages.dev`

或走 Git：把本包推到 Gitee/GitHub → Pages 里连接仓库 → **构建命令留空**、输出目录填 `/`。

### 方式 C · 自己的服务器（Nginx）

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/crossborder;   # 把包内 4 项放进这个目录
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
```

## 三、上线后 1 分钟验收

1. 打开网址 → 启动页只有一个「💾 进入本地模式」按钮（无账号表单、无加载等待）
2. 点进入 → 左侧 10 个模块全部可点开
3. 在「日程待办」加一条 → 按 F5 刷新 → 重新进入 → 数据还在 ✅
4. F12 → Network 面板：除汇率/翻译外，没有任何对 supabase.co 的请求 ✅

## 四、用户需要知道的三件事（建议原话转达）

1. **数据在哪**：只在用户自己的浏览器里（IndexedDB），换浏览器/换设备/清浏览器缓存 = 数据不带走。请用「数据管理 → 导出」定期备份 JSON 文件；换设备时「导入」恢复。
2. **多设备不同步**：本版本没有服务器，各设备各存各的。要迁移就导出/导入备份文件。
3. **隐私**：应用不收集任何信息，服务器上只有静态文件，没有任何数据库。

## 五、常见问题

| 问题 | 处理 |
|---|---|
| 页面白屏/样式乱 | 上传时漏了 css/ 或 js/；确保 index.html 在根目录 |
| 改了代码不生效 | 把 index.html 里所有 `?v=67` 递增为 `?v=68` 再上传 |
| 用户说数据丢了 | 大概率换了浏览器或清了缓存。让 TA 在原浏览器里找；无法找回（这正是纯本地的代价） |
| 「分享」按钮点了提示不支持 | 正常。本版本无服务器，请用数据管理里的导出 |
| 想恢复云端版 | 使用另一个包「跨境百宝囊-腾讯云部署包」（含 Supabase + SCF） |

## 六、后续更新代码的方法

改了任何 js/css 后：

1. 把 `index.html` 里所有 `?v=67` 统一 +1（防止用户浏览器用缓存旧文件）
2. 重新上传整个目录（方式 A/B 都是覆盖上传）
